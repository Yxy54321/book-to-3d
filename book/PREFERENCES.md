# 全书默认偏好

用户在第一章时拍板的设定，作为全书默认。所有章节项目只读。

**覆盖规则**：某一章确实不适用某条默认时，P1 规划或 P2 体验设计可以覆盖它，但必须同时满足：(1) 在 `design/decisions.md` 写明“默认是什么、为什么本章不适用、替代方案是什么、替代方案如何仍服务于默认背后的目的”；(2) 由至少两个独立评审视角（其中一个必须是叙事与情感导演）确认覆盖理由成立；(3) 覆盖只对本章有效。标“不可覆盖”的条目任何章节都不能改。

| 编号 | 项 | 默认 | 背后的目的 | 可否覆盖 |
|---|---|---|---|---|
| F1 | 体验者视角 | 每幕换一个**真实在场者**的身份，身份服务于这一幕的核心动作 | 让体验者有理由在场、有手可动，产生亲历感 | 可覆盖。常见正当理由：本幕没有可信的在场者能做核心动作；敏感性要求非参与视角（见 `SENSITIVITY.md`）；本幕是纯机制讲解，没有现场 |
| F2 | 知识深度 | 分层：L0 实物与直觉（默认路径只需要这一层）；L1 真实数值；L2 规则、公式与史料出处。L1/L2 由体验者主动展开 | 大众能走通，想深究的人有路可走 | 层级可增减，但“默认路径不要求 L1/L2”不可覆盖 |
| F3 | 机制真实运行 | 章节核心若是一种可计算的机制，体验中必须真实运行（见 `loop/LOOP.md` 宪法 C3） | 亲历感来自真实的因果 | **不可覆盖** |
| F4 | 自动化 | 全自动，预算无上限，无人工关口；唯一的停止规则是“连续多轮无进展→结束当前阶段、进入下一阶段” | 用户的运行方式 | **不可覆盖** |
| F5 | 一次一章 | 每个章节项目只做一章；不读取其他章节项目的任何产物 | 章节之间的串联方式尚未确定，先保持独立 | **不可覆盖** |
| F6 | 全书风格 | 由用户审定的 `book-style/STYLE_CONTROL.md` 规定四种可选风格（archival 档案纪实、paper 纸本世界、editorial 编辑插画、miniature 桌面微缩模型）及共用规则（镜头语法取自 Gemini 版第一章、简化五官、不设语义色）；用户选定一种（`SELECTION.json`），全书只做这一种。章节只能在其范围内扩展 | 用户要求各章美术风格一致 | **不可覆盖** |
| F7 | 时长 | 默认路径 15–20 分钟 | 一次坐下能体验完 | 可在 10–25 分钟内按章节内容调整，写明理由 |
| F8 | 语言 | 界面中文；书中原话保留英文并附中文译文（译文标注为译） | 用户的阅读语言，同时保留原文的分量 | 不可覆盖 |
| F9 | 平台 | 桌面浏览器（Chrome / Safari），本地离线运行；手机不在验收范围 | 与风骇岛一致的本地运行方式 | 不可覆盖 |
| F10 | 首个垂直切片 | 选本章交互风险最高、又最贴近核心学习目标的那一幕先做到成品质量 | 先证明交互语法成立，再铺开 | 选哪一幕由 P2 决定 |
| F11 | 与用户交流 | 中文，平实，少术语；必须用术语时一句话解释它对用户意味着什么 | 用户偏好 | 不可覆盖 |
