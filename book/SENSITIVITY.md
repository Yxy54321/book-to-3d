# 全书敏感性指南

所有章节项目只读。P1 规划必须逐条扫描本章，把适用的条目写进 `design/chapter-constitution.md`（派生宪法），P1 出口时冻结，之后与 `loop/LOOP.md` 的宪法同级，不可放松。

扫描方法：对下表每一类，在本章正文里找出所有相关段落（附页码），判断“本章是否触及”。触及的，写出具体约束；不触及的，写“不触及”并给一句理由。不允许整类跳过。

| 类别 | 本书中的典型情形 | 默认约束 |
|---|---|---|
| **S1 在世真实人物** | 书中大多数人物仍然在世：研究者、创业者、公司高管、记者 | 风格化呈现，不做照片级肖像；外貌只取正文描述，不丑化、不讨好；不把正文没有的话或观点放进他们嘴里；推动流程的功能性台词标为改编，且不得表达立场；正文中带归因的说法（“据某人说”“许多人认为”）保留归因，不改写成定论 |
| **S2 已故人物与死亡** | 例如第一章 Rosenblatt 之死 | 不游戏化：没有分数、失败状态、“救人”或“改变结局”的操作；视角不属于对死亡可能负有责任的人；不展示死亡过程；保留正文的不确定性 |
| **S3 健康与身体** | 例如序章与多处提到的 Hinton 的背伤（因此不坐下）；其他人物的伤病与手术 | 只按正文陈述，作为人物处境的一部分；不作笑点，不夸张，不变成玩法上的“惩罚” |
| **S4 种族、性别与歧视** | 例如第15章 BIGOTRY 及其题词所指的事件；书中涉及的偏见与多样性问题 | 不让体验者“执行”歧视性行为作为玩法；不为了冲击效果而复现冒犯性的图像或标签——需要呈现时，以克制方式、从受影响者的视角呈现后果；含粗口的原话可在原文语境中引用，不放大、不做标题装饰 |
| **S5 军事与武器** | 例如第16章 WEAPONIZATION 涉及的军事合作争议 | 不做操作武器、瞄准、打击的玩法；呈现决策、争议与人的立场，而不是战斗 |
| **S6 虚假信息、伪造与操纵** | 例如第13章 DECEIT（生成逼真人脸）、第17章 IMPOTENCE（平台被利用） | 体验里生成的任何“逼真”内容不得是真实人物；必须明显可辨为合成；不产出可被拿出体验之外滥用的伪造素材 |
| **S7 国家、政治与地缘** | 例如第14章 HUBRIS 大量涉及中国；第12章 DREAMLAND 涉及百度 | 不做民族或国家的刻板形象；按正文呈现各方行为与说法，不加作者没有的评判；地名、机构名照实 |
| **S8 公司与商标** | Google、Facebook、Microsoft、DeepMind、Baidu、OpenAI 等 | 不复制公司标志作为画面主元素；用文字名称或中性招牌；不暗示任何公司认可本体验；涉及公司行为时以正文为准，保留归因 |
| **S9 金钱、竞价与赌博场景** | 例如序章在赌场酒店进行的拍卖；收购价格、薪酬 | 金额照正文；可以让体验者参与竞价类交互，但不得有奖励性赌博机制；体验者的选择与历史结果并列呈现，不改写结果 |
| **S10 私人通信与内部文件** | 书中引用的邮件、内部讨论 | 只引用正文已经公开的内容，遵守引文预算；不虚构邮件全文 |
| **S11 争议与未定论题** | 例如 AI 风险、AGI、自动化与就业等观点之争（第9、18、19、20章等） | 呈现各方观点时不替作者或体验下结论；给每一方与正文相称的篇幅；体验者可以自己选择站位，但体验不奖励某一方 |
| **S12 版权** | 原书文字、照片 | 原书 PDF 与抽取文本只在 `source/`，不进入产物；逐字引文遵守预算；参考图只作建模参考，除非许可允许，不进入产物 |

## 派生宪法的写法

`design/chapter-constitution.md` 每一条写成：`CC-n｜类别｜约束（可检验的句子）｜依据（正文页码）｜如何检验（哪个评审视角或自动检查）`。至少覆盖本章触及的每个类别。尊重与版权视角在每个阶段的出口复核中逐条核对。
